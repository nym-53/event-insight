# Event Insight 3.0

イベントで回収したアンケートの回答を入力・集計・可視化するWebアプリケーションです。

## 開発背景

大学の企業連携活動でイベント運営に携わった際、紙アンケートの回答結果をイベント終了後に集計していたため、開催中に来場者の回答傾向を把握できないという課題を感じました。

一方、スマートフォンでの回答が難しい来場者もいるため、回答方法を完全にデジタル化するのではなく、紙アンケートを残しながら、運営側の集計・分析を効率化する仕組みを考えました。

## 主な機能

- イベントの登録・管理
- アンケートの質問作成（単一選択・複数選択・5段階評価・自由記述）
- 回答の登録・編集・削除
- 回答数・割合のグラフ表示
- 2項目を組み合わせたクロス集計
- CSV形式での回答データ出力

## 工夫した点

### 1. 利用者に配慮した仕組み

来場者の回答方法は紙のまま残し、運営側が回答を入力することで、デジタル操作が苦手な方の回答機会を確保できるようにしました。

### 2. 回答結果の自動集計・可視化

入力した回答が集計結果に反映され、回答数や割合をグラフで確認できるようにしました。年代や理解度などの回答傾向を把握しやすくすることを意識しました。

### 3. 多角的な分析

2つの質問を組み合わせたクロス集計機能を設け、単純な集計だけでは分からない回答傾向も比較できるようにしました。
