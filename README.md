# Event Insight 3.0

イベントで回収したアンケートの回答を入力・集計・可視化するWebアプリケーションです。

## 開発背景
紙アンケートではイベント終了後に集計する必要があり、開催中に回答傾向を把握できないという課題がありました。スマートフォンでの回答が難しい来場者に配慮して紙の回答方法を残しながら、運営側の集計・分析を効率化することを目的に制作しました。

## 主な機能
- イベントの登録・管理
- アンケートの質問作成
- 回答の登録・編集・削除
- 回答数・割合のグラフ表示
- 2項目のクロス集計
- CSV形式での回答データ出力

## 使用技術
- React
- TypeScript
- CSS
- Vite
