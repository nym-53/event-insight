# Event Insight 3.0

**イベントアンケートの回答を入力・集計・可視化するWebアプリケーション**

大学の企業連携活動で感じた課題をきっかけに、イベント運営におけるアンケート集計・分析の効率化を目的として制作しました。

### アプリを体験する

https://nym-53.github.io/event-insight/

初回アクセス時には、架空のイベント1件・質問7問・回答30件のデモデータが用意されており、グラフ表示やクロス集計などの機能を試すことができます。

※ デモデータは機能確認用に作成した架空のデータであり、実際のイベントで収集した回答ではありません。

## 開発背景

大学の企業連携活動でイベント運営に携わった際、紙アンケートの回答結果をイベント終了後に集計していたため、開催中に来場者の回答傾向を把握できないという課題を感じました。

一方、スマートフォンでの回答が難しい来場者もいるため、回答方法を完全にデジタル化するのではなく、紙アンケートを残しながら、運営側の集計・分析を効率化する仕組みを考えました。

## 主な機能

- **イベント管理**：イベントの登録・管理
- **アンケート作成**：単一選択・複数選択・5段階評価・自由記述の質問を作成
- **回答管理**：回答の登録・編集・削除
- **データ可視化**：回答数・回答割合をグラフで表示
- **クロス集計**：2つの質問項目を組み合わせて回答傾向を比較
- **CSV出力**：回答データをCSV形式で出力

## 工夫した点

### 1. 利用者に配慮した仕組み

来場者の回答方法は紙のまま残し、運営側が回答を入力する仕組みを採用しました。

集計の効率化だけでなく、デジタル操作が苦手な方の回答機会を確保することも重視しました。

### 2. 回答結果の自動集計・可視化

入力した回答が集計結果に反映され、回答数や割合をグラフで確認できるようにしました。

年代や理解度などの回答傾向を把握しやすくすることで、イベント運営中の状況確認や説明方法の見直しに活用できる仕組みを目指しました。

### 3. 複数の視点から分析できる画面設計

単純な回答数の集計に加え、2つの質問を組み合わせたクロス集計機能を設けました。

例えば、年代ごとの理解度や、事前認知度と実践意向の関係など、複数の項目を組み合わせて比較できるようにしました。

## 開発状況・注意事項

本アプリは、大学での活動をきっかけに制作したプロトタイプです。

- 回答データは利用者のブラウザ内に保存されます。
- 複数端末間でのデータ共有には対応していません。
- デモデータは架空のものであり、実際の調査結果を示すものではありません。
- 現時点では、イベント運営における集計・分析機能の検証を目的としています。
